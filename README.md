# GT Course Notes

A personal archive of resources and compiled notes from classes taken at Georgia Tech. Notes are written in LaTeX and compiled to PDF, organized by course.

## Structure

Each course has its own folder containing dated notes (`.tex` source and compiled `.pdf`):

```
MATH 1564 - Linear Algebra with Abstract Vector Spaces/
CS 2050 - Discrete Mathematics/
```

## Courses

- **MATH 1564 — Linear Algebra with Abstract Vector Spaces**: linear equations, systems of equations, row reduction (RREF), vector spaces, and related topics.
- **CS 2050 — Discrete Mathematics**: propositional logic, logical operators and precedence, truth tables, and related topics.
